# Changelog

All notable changes to this project are documented here.
Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), versioning: [SemVer](https://semver.org/).

## [Unreleased]

### Added
- Repository scaffold, MIT license, CI (ruff + pytest).
- Shared library `pocketknife`: 2D hull, minimum rectangle, polylabel, region
  grouping, minimum oriented box, layer-copy planning.
- Approved commands (in `commands/`, documented in `docs/commands/`): `pkLayerColorFromMaterial`, `pkCopyToLayerCopy`,
  `pkInnerPoint`, `pkMinBoundingRect`, `pkMinBoundingBox`, `pkOrientToMinRect`.
- Icons: six command icons (light and dark, Rhino 9 color language), plug-in logo,
  site favicon, generated by `tools/build_icons.py`.
- Rhino 8 project `project/pocketknife.rhproj` with the six commands, the four
  Grasshopper components (`project/pocketknife.gh`) and the `pocketknife`
  library, generated by `tools/build_project.py`; `tools/build_plugin.py`
  builds the `.rhp`, `.gha` and the Yak package with `project/manifest.yml`.
- Grasshopper components (scripts, to be tested): `pkInnerPoint` with accuracy
  input, `pkMinBoundingBox`, `pkMinBoundingRect`, `pkOrientToMinRect`.

- Curve commands (in `commands/`, documented in `docs/commands/`, with
  Grasshopper components and icons): `pkCleanCurves`, `pkClipCurves`,
  `pkRebuildCurves`, `pkFootprint`. Logic in `curvegraph`, `intervals`,
  `polyfit` and `footprint`, Rhino side in `rhinocurves`, `rhinoclip`,
  `rhinorebuild` and `rhinofootprint`.

- Release script `tools/release.py` (`check`, `test`, `publish`): checks the
  version, `CHANGELOG.md` and the local build, then tags, creates the GitHub
  release and pushes to Yak. Documented in `docs/releasing.md`.

### Fixed
- `pkCopyToLayerCopy`: selected layers below another selected layer no longer split the copied tree.

### Changed
- `pkMinBoundingBox`: `Group=Yes` by default, slow-computation warning, progress bar and Esc.
