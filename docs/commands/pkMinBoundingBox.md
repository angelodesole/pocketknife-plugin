# pkMinBoundingBox

Adds the minimum-volume oriented bounding box of the objects.

| Option | Effect |
|---|---|
| `Accuracy=Fast|Normal|Precise` | Number of directions tested before the local refinement. |
| `Group=Yes` | One box for all objects (default). |
| `Group=No` | One box per object. |

## Notes

Slow computations show a warning and a progress bar; press Esc to stop. Flat results become a rectangle.
