# Icons

Generated by `tools/build_icons.py` (edit the script, not the SVG files):

```bash
pip install cairosvg
python tools/build_icons.py
```

## Command icons (24 px grid)

They follow the Rhino 9 design language: neutral geometry, and only the element
the command creates or changes in the color of its category (Open Color):

| Color | Hex | Category |
|---|---|---|
| Blue | `#339af0` | NURBS geometry: points, curves, surfaces, solids |
| Lime | `#82c91e` | Transform and edit |
| Orange | `#ff922b` | Attributes: layers, materials, colors |
| Grape | `#be4bdb` | Meshes (reserved) |
| Cyan | `#22b8cf` | SubD (reserved) |

Each icon has a light (`name.svg`) and a dark (`name-dark.svg`) variant;
PNG exports are in `png/` at 16, 24, 32, 48 and 64 px.

## Plug-in logo

`pocketknife-logo.svg`: minimal 3D pocket knife, used for the Yak package and
the README. PNG exports from 16 to 512 px.

## Site favicon

`site-favicon.svg`: flat mark in the extrdd.com style (ink `#1C1C1A` on paper
`#F5F5F0`, automatic dark mode), for the project site.
